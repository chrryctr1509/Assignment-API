## Fix & Debug Protocol

SEBELUM mengubah code apapun saat fix/debug:
1. Cek zombie processes: `lsof -i -P -n | grep LISTEN`
2. Cek stale build: hapus cache/compiled output, rebuild, test lagi
3. Cek git diff: apa yang berubah terakhir?
4. Catat baseline: test mana yang pass sekarang?

SAAT fix: minimal changes, jangan refactor, jangan ubah config tanpa bukti.
Jika gagal: REVERT (`git checkout -- [files]`), coba pendekatan lain.
Jika 2x gagal: TANYA user.
