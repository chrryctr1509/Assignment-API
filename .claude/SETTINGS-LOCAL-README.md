## How to Fill

### Telegram (Optional — enables remote control)

| Field | Where to Get | Example |
|-------|-------------|---------|
| `TELEGRAM_BOT_TOKEN` | Telegram → @BotFather → /newbot | `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz` |
| `TELEGRAM_CHAT_ID` | Telegram → @userinfobot → /start | `5211366883` |

Leave empty if you don't use Telegram features. All pipeline features work without it.

### Git Platform (Choose ONE — GitLab OR GitHub)

#### GitLab
| Field | Where to Get | Required Scopes |
|-------|-------------|-----------------|
| `GITLAB_TOKEN` | GitLab → User Settings → Access Tokens | `api`, `read_repository`, `write_repository` |
| `GITLAB_REPO_URL` | Your repo URL | `https://gitlab.com/username/repo-name` |

#### GitHub
| Field | Where to Get | Required Scopes |
|-------|-------------|-----------------|
| `GITHUB_TOKEN` | GitHub → Settings → Developer Settings → PAT | `repo` (full control) |
| `GITHUB_REPO_URL` | Your repo URL | `https://github.com/username/repo-name` |

**Only fill ONE platform.** Framework auto-detects which one is configured.
If both filled, GitLab takes priority.

### Permissions (Pre-configured)

The `permissions.allow` array pre-approves common commands so Claude Code
doesn't prompt you every time. Default includes:

- Telegram management commands
- Docker compose/exec commands
- Git read-only commands (status, diff, log, branch)

**You may add more** if Claude Code frequently prompts for specific commands.
Format: `Bash(command pattern)` — wildcards `*` supported.

### Example: Minimal (GitLab only, no Telegram)

```json
{
  "env": {
    "TELEGRAM_BOT_TOKEN": "",
    "TELEGRAM_CHAT_ID": "",
    "GITLAB_TOKEN": "glpat-xxxxxxxxxxxxxxxxxxxx",
    "GITLAB_REPO_URL": "https://gitlab.com/myteam/myproject",
    "GITHUB_TOKEN": "",
    "GITHUB_REPO_URL": ""
  },
  "permissions": {
    "allow": [
      "Bash(chmod +x .claude/telegram/*.sh)",
      "Bash(bash .claude/telegram/manage.sh stop)",
      "Bash(bash .claude/telegram/manage.sh start)",
      "Bash(bash .claude/telegram/manage.sh start-channels)",
      "Bash(bash .claude/telegram/manage.sh status)",
      "Bash(docker compose:*)",
      "Bash(docker exec:*)",
      "Bash(git status)",
      "Bash(git diff:*)",
      "Bash(git log:*)",
      "Bash(git branch:*)"
    ]
  }
}
```

## Troubleshooting

**"Claude keeps asking permission for docker compose up"**
→ Add `"Bash(docker compose up:*)"` to permissions.allow

**"PR creation fails — no GitLab/GitHub token"**
→ Fill GITLAB_TOKEN or GITHUB_TOKEN with correct scopes

**"Telegram notifications not working"**
→ Run: `bash .claude/telegram/setup-telegram.sh` to validate token + chat ID

**"JSON parse error when Claude starts"**
→ Validate JSON: `jq empty .claude/settings.local.json`
→ Common issue: trailing comma before closing `}`
